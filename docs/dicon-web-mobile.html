DICON Web no celular

Guia rápido para o coordenador instalar a console (versão mobile) na tela inicial do celular.

O que é

A DICON Web é a console de acompanhamento das vistorias de conectividade — cobertura, técnicos ao vivo, lista de locais e relatório final. Tem duas telas:

TelaPara quêEndereço
Desktop ?app=web Computador — tudo (inclui Relatório final e Acesso). …/exec?app=web
Mobile ?app=mobile Celular — Ao vivo, Vistorias e Painel, enxuto. …/exec?app=mobile

Endereço da versão mobile (produção):

https://script.google.com/macros/s/AKfycbylhIAahOf0coAHwpOH2OCMbySmfeZR1feT-JFG5aw69GGrtRWYAnxtcL4b3carWYNy0w/exec?app=mobile

Na console de desktop também há um atalho 📱 mobile no topo.

Antes de tudo: abra no Chrome, não na janelinha do WhatsApp Links abertos dentro do WhatsApp (ou outro app) usam um navegador interno que não está logado na conta Google → dá "Não foi possível abrir o arquivo". Sempre abra a URL no Google Chrome do celular.

1Confirmar a conta no Chrome do celular

A console só abre para contas @tre-ma.jus.br autorizadas.

  1. No Chrome, abra myaccount.google.com.
  2. Toque no círculo do perfil (canto superior direito) → veja as contas logadas.
  3. A conta ativa precisa ser a corporativa, ex.: george.castro@tre-ma.jus.br (aparece "Gerenciado por tre-ma.jus.br").
  4. Se não estiver: Adicionar outra conta → entrar com a conta @tre-ma.jus.br.

2Levar o endereço até o celular

Digitar a URL na mão dá erro (é enorme). Escolha um jeito:

A) Enviar do computador (Chrome sincronizado) — recomendado

  1. No Chrome do computador, abra a URL mobile (acima) — confira que carrega.
  2. ⋮ (três pontos) → Transmitir, salvar e compartilhar → Enviar para seu dispositivo.
  3. Escolha o seu celular na lista.
  4. No celular aparece uma notificação do Chrome → toque nela → a página abre no Chrome do celular.

B) QR Code

  1. No Chrome do computador, na mesma URL: ⋮ → Transmitir, salvar e compartilhar → Criar QR code.
  2. Abra a câmera do celular e aponte para o QR → toque no link que aparece → abre no Chrome.

C) E-mail para você mesmo

  1. Mande a URL por e-mail para você mesmo.
  2. Abra no Gmail → toque no link. Se abrir numa janelinha, use ⋮ → Abrir no Chrome.

3Instalar na tela inicial

Com a console já aberta no Chrome do celular:

  1. ⋮ (três pontos, canto superior direito).
  2. Toque em "Instalar e criar atalho" (em algumas versões: "Adicionar à tela inicial").
  3. Escolha Instalar (abre em tela cheia, sem barra de endereço).
  4. Ajuste o nome para DICON Web → Adicionar / Instalar.
  5. O ícone aparece na tela inicial. Pronto — toque nele para abrir.

Se der problema

ApareceCausa / o que fazer
"Não foi possível abrir o arquivo" (com logo do Google Drive) Abriu no navegador interno de outro app (WhatsApp, e-mail) ou a conta ativa não é a @tre-ma.jus.br. Abra no Chrome e confira a conta (passo 1).
"Sem acesso" mostrando o seu e-mail O e-mail não está autorizado. Um administrador precisa incluí-lo na aba Acesso (na própria console desktop → aba Acesso).
Tela de login do Google Escolha a conta @tre-ma.jus.br. Na 1ª vez, também aparece uma tela pedindo para autorizar o script → autorize.
O Ao vivo não atualiza sozinho Ele atualiza a cada ~45 s e pausa quando o celular está com a tela travada ou o Chrome em segundo plano. Toque no ↻ no topo para forçar.
Deu certo quando… o ícone DICON Web está na tela inicial e, ao tocar, abre a faixa com cobertura % · testados · pendentes e as abas Ao vivo · Vistorias · Painel.
